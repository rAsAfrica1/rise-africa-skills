â  SAFETY WARNING â User Data, Payments & Device Security

Mobile apps that handle personal data, mobile money transactions, or location tracking carry serious legal and financial risk. Before you publish:

  • Never store passwords or PINs in plain text. Use hashed storage (bcrypt, Argon2) and Android Keystore for sensitive keys. A single data breach can expose thousands of users.
  • Comply with data protection laws. South Africa's POPIA, Kenya's Data Protection Act 2019, Nigeria's NDPR, and Zimbabwe's Cyber and Data Protection Act all require user consent and secure data handling. Penalties can reach millions of dollars.
  • Use HTTPS for all API calls. Never transmit mobile money details over unencrypted connections. Man-in-the-middle attacks on public WiFi are common in African urban centres.
  • Test payment flows with small amounts first. A bug in a mobile money integration can duplicate charges or lose funds â always verify with a USD 1 test transaction before going live.
  • Request minimum permissions. Users abandon apps that demand unnecessary access to contacts, camera, or location. Request only what the feature requires.
