Robotics with Python

Sense, think, act — a hundred times a second. That loop is every robot ever built.

Ages 12–168 modules 🪨 Starts with no device

You will learn control the way engineers actually think about it: as a loop that reads the world, decides, and moves — then does it again immediately. We start in the sand because a control loop is much easier to understand when you have walked one, and we finish with a servo arm you built from salvage and drive with your own Python.

For a parent or teacher

Your teenager will learn control loops, state machines, PWM and proportional control conceptually first, then implement them in Python on a shared phone and finally on salvaged hardware. By module 8 they can build and program a working servo-driven sorting arm and explain the control logic behind it.
