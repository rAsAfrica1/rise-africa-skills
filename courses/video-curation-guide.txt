RISE AFRICA SKILLS PLATFORM
VIDEO CURATION & SOURCING GUIDE
================================================================================

OVERVIEW
--------
This guide helps you find and legally embed free, high-quality educational videos
for the Rise Africa Skills platform. All recommendations use Creative Commons or
similar open licenses suitable for educational use.

KEY PRINCIPLES
--------------
1. Only use videos with proper licenses (Creative Commons, Educational Use)
2. Always credit the original creator
3. Prefer short videos (5-15 minutes for each of 5 videos per module)
4. Ensure videos have clear audio and relevant content
5. Test embedding before publishing

SECTION 2: HOW TO LEGALLY EMBED VIDEOS
================================================================================

YOUTUBE EMBEDDING
-----------------
Method 1: Direct YouTube Embed (Most Videos)

1. Find the video on YouTube
2. Click "Share" → "Embed"
3. Copy the iframe code
4. Insert into module HTML:

   <div class="video-container">
     <iframe
       src="https://www.youtube.com/embed/VIDEO_ID"
       title="Video Title"
       allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
       allowfullscreen>
     </iframe>
   </div>

5. Add video credits below player:
   <p>Video by: [Creator Name] | License: CC-BY | Source: [Channel]</p>

Method 2: Using Creative Commons Search

1. Go to: search.creativecommons.org
2. Search for video content
3. Filter by license (CC-BY or CC-BY-SA preferred)
4. Verify creator allows commercial/educational use
5. Follow attribution requirements

VIMEO EMBEDDING
---------------
1. Check if video allows embedding
2. Click "Share" → "Embed"
3. Use iframe code provided
4. Some Vimeo videos are Creative Commons - verify license

DIRECT DOWNLOAD (For Offline Use)
---------------------------------
Some platforms allow video downloads for offline viewing:

1. OER Commons (oercommons.org)
   - Many videos available for download
   - License clearly marked
   - Can host on your own server

2. Open Educational Resources (OER) Videos
   - Khan Academy videos
   - MIT OpenCourseWare videos
   - University lecture recordings

LICENSING VERIFICATION CHECKLIST
---------------------------------
Before embedding any video, verify:

□ Is the video in the public domain or Creative Commons licensed?
□ What is the specific license (CC-BY, CC-BY-SA, CC-BY-NC-SA)?
□ Does license allow commercial/educational use?
□ Does license allow derivative works/modifications?
□ Are attribution requirements clear?
□ Can video be downloaded for offline use?
□ Is there expiration date on the license?
□ Does the hosting platform allow embedding?


SECTION 3: ATTRIBUTION & COMPLIANCE
================================================================================

PROPER ATTRIBUTION FORMAT
--------------------------
For each video, include:

"[Video Title]" by [Creator Name] is licensed under CC-BY [version]
Full attribution: [Full Name of Creator/Organization]
License link: [Link to CC license]
Source URL: [Direct video URL]

EXAMPLE:
"How Farmers Combat Climate Change" by World Food Programme
is licensed under CC-BY 4.0
License: https://creativecommons.org/licenses/by/4.0/

COPYRIGHT COMPLIANCE STATEMENT
------------------------------
Include this in your module footer:

"Educational materials in this module include videos licensed under Creative
Commons. Full attribution is provided for each video. All videos are used
for educational purposes in accordance with their respective licenses."

DMCA COMPLIANCE
---------------
- Only use videos with explicit permission or CC licenses
- Never circumvent DRM (Digital Rights Management)
- Respect YouTube's Terms of Service
- If a creator requests removal, comply immediately
- Keep records of licenses and permissions

RIGHTS VERIFICATION TRACKING
----------------------------
Create a spreadsheet for each course tracking:

Module | Video Title | Creator | License | Link | Verified Date | Notes

Example:
Module 1 | Intro to Farming | WFP | CC-BY 4.0 | youtube.com/watch?v=xyz | 2024-01-15 | Verified OK

SECTION 5: VIDEO QUALITY STANDARDS
================================================================================

TECHNICAL SPECIFICATIONS
------------------------
For optimal viewing on all devices:

- Resolution: Minimum 720p (1280x720)
- Aspect ratio: 16:9 (widescreen)
- Frame rate: 24-30 fps
- Audio: Clear, mono or stereo
- File format: MP4 (H.264), WebM
- Bitrate: 500-2000 kbps (for streaming)

CONTENT QUALITY CHECKLIST
--------------------------
□ Video is clearly audible (not muffled, good levels)
□ Visuals are clear (not too dark, not blown out)
□ Content matches module learning objectives
□ Length is appropriate (5-15 minutes)
□ No unnecessary background noise
□ Captions/subtitles available (if possible)
□ Culturally appropriate for African learners
□ No political or religious bias
□ No commercial advertising (or minimal)
□ Production value reasonable (not too amateurish)

ACCESSIBILITY CONSIDERATIONS
-----------------------------
- Provide transcripts when possible
- Enable captions (YouTube auto-generates or upload)
- Use clear audio (easy to understand accents)
- Visual content should be explained verbally
- Provide video descriptions for visually impaired users
- Consider multiple language options


SECTION 6: BUILDING YOUR COURSE VIDEO LIBRARY
================================================================================

WORKFLOW FOR EACH COURSE

Step 1: Research Phase (1-2 days)
---------------------------------
1. Identify 5 key learning outcomes for each module
2. Search for videos on each topic using sources listed above
3. Watch 10-15 candidate videos per module topic
4. Evaluate videos using quality checklist
5. Select 5 best videos per module

Step 2: Verification Phase (1 day per module)
---------------------------------------------
1. Verify license for each video
2. Check attribution requirements
3. Test embedding in HTML
4. Create attribution text
5. Document in tracking spreadsheet

Step 3: Integration Phase (2-4 hours per module)
-----------------------------------------------
1. Add video metadata to moduleData in HTML
2. Insert embed URLs
3. Add video descriptions
4. Add attribution statements
5. Test offline/online viewing

Step 4: Quality Assurance (2-4 hours per module)
-----------------------------------------------
1. Test all 5 videos load correctly
2. Verify audio and video quality
3. Check attribution is visible
4. Test on mobile device
5. Verify in offline mode (if using ServiceWorker)

TIME ESTIMATE FOR 56 COURSES (336 MODULES)
-----------

Research: 336 modules × 2 hours = 672 hours
Verification: 336 modules × 2 hours = 672 hours
Integration: 336 modules × 1 hour = 336 hours
QA: 336 modules × 1.5 hours = 504 hours
                        Total = 2,184 hours (~55 working weeks)

RECOMMENDATION:
- Hire 2-3 content researchers
- Work in parallel by course category
- Reuse videos across similar modules when appropriate
- Start with highest-demand courses first


SECTION 7: BACKUP & OFFLINE STRATEGIES
================================================================================

CREATING OFFLINE VIDEO LIBRARY

Option 1: Download Selected Videos
---------
For highest-impact videos, consider:
1. Using youtube-dl or yt-dlp to download
2. Verify license allows downloads
3. Store locally and host on eGranary/offline platform
4. Sync via USB drives to offline devices

Option 2: Use Offline Educational Platforms
---------------------------------------------
- RACHEL (rachel.digitallibrary.org)
- Offline Wikipedia with WikiPlex
- Open Stack books with videos
- Khan Academy offline app

Option 3: Create Own Mirrored Library
--------------------------------------
1. Host videos on your own server
2. Use CDN for distribution
3. Create backup copies
4. Implement fallback if YouTube goes down

CODE EXAMPLE: Fallback Video Loading
-----

```javascript
async function loadVideoWithFallback(videoId, fallbackUrl) {
  try {
    // Try to load from YouTube first
    return await loadYouTubeVideo(videoId);
  } catch (error) {
    console.log('YouTube unavailable, using fallback');
    // Use locally hosted or cached version
    return await loadLocalVideo(fallbackUrl);
  }
}
```
