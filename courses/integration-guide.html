Overview

The Rise Africa Skills Learning Module System is a comprehensive platform designed to deliver video-based education with hands-on implementation exercises and assessments. It supports both online and offline modes with automatic synchronization.

Key Features:
  • Reusable HTML module template with responsive design
  • JavaScript progress tracker with offline-first architecture
  • Local storage using browser localStorage API
  • Automatic sync when device comes online
  • Assessment and project submission system
  • Points and badge system for gamification
  • Fully mobile-responsive

Setup Instructions

Step 1: Prepare Your Environment

1.1 Set Up Web Server

Use any web server (Apache, Nginx, Node.js Express) to serve the HTML files. For local development:

# Python 3 python -m http.server 8000 # Node.js npx http-server . # Or use VS Code Live Server extension
1.2 Configure Backend Sync Endpoint

Create an API endpoint to receive sync data. Example structure:

POST /api/progress/sync { "userId": "user123", "timestamp": "2024-01-15T10:30:00Z", "updates": [ { "moduleId": "module-1", "videosWatched": 3, "stepsCompleted": 4, ... } ] }
1.3 Create Database Schema

Store synced progress in your database:

CREATE TABLE module_progress ( id INT PRIMARY KEY AUTO_INCREMENT, user_id VARCHAR(255), module_id VARCHAR(255), course_id VARCHAR(255), videos_watched JSON, steps_completed INT, quiz_score INT, project_submitted BOOLEAN, completed_at TIMESTAMP, synced_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, INDEX(user_id, module_id) );

Step 2: Configure Module Template

2.1 Customize Module Data

Edit the `moduleData` object in each module HTML file to include your course-specific content:

const moduleData = { moduleId: 'farming-module-1', courseName: 'Sustainable Pig Farming', moduleNumber: 1, totalModules: 6, title: 'Introduction to Pig Farming', // ... add your videos, materials, steps, etc. };
2.2 Add Course-Specific Videos

Replace placeholder YouTube embed URLs with your actual video sources (see Video Curation Guide)

videos: [ { id: 'vid-1-1', title: 'Your Video Title', duration: '8:45', embedUrl: 'https://www.youtube.com/embed/VIDEO_ID', source: 'Video Provider' }, // ... more videos ]
2.3 Customize Branding

Update CSS variables and colors in module-template.html to match your brand:

/* In module-template.html */ .module-header { background: linear-gradient(135deg, YOUR_COLOR_1 0%, YOUR_COLOR_2 100%); }

Step 3: Integrate with Enrollment System

3.1 Link Module from Course Page

In your course listing, link to modules:

<div class="module-link"> <a href="/courses/farming/module-1-intro.html?userId=USER_ID&courseId=farming"> Module 1: Introduction to Pig Farming </a> </div>
3.2 Pass User Context to Module

Extract user ID and course ID from URL query parameters:

// Add to module-template.html before moduleData definition const urlParams = new URLSearchParams(window.location.search); const userId = urlParams.get('userId') || 'anonymous'; const courseId = urlParams.get('courseId'); // Save current user for progress tracking localStorage.setItem('currentUserId', userId); localStorage.setItem('currentCourseId', courseId);
3.3 Sync Progress Back to Enrollment

After module completion, update enrollment system:

function completeModule() { // ... existing completion logic // Notify enrollment system fetch('/api/enrollment/module-complete', { method: 'POST', headers: {'Content-Type': 'application/json'}, body: JSON.stringify({ userId: userId, moduleId: moduleData.moduleId, completedAt: new Date().toISOString(), score: calculateModuleScore() }) }); }

API Reference

Client-Side API (progress-tracker.js)

Method Description Example
progressTracker.updateProgress(moduleId, data) Update module progress progressTracker.updateProgress('mod-1', { videosWatched: 3 })

Server-Side API Requirements

POST /api/progress/sync

Receives progress updates from clients

Request Body:

{ "userId": "user123", "timestamp": "2024-01-15T10:30:00Z", "updates": [ /* module progress objects */ ], "clientVersion": "1.0.0" }

Response:

{ "success": true, "synced": 3, "timestamp": "2024-01-15T10:30:05Z" }

Performance Optimization

Best Practices:
  • Lazy Load Videos: Don't autoplay all 5 videos at once
  • Compress Media: Use modern video formats (MP4 with H.264)
  • Cache Strategy: Use Service Workers for offline access
  • Database Indexing: Index on (user_id, module_id) for fast lookups
  • CDN Delivery: Serve videos from CDN (Cloudflare, AWS CloudFront)
  • Pagination: Load modules on-demand, not all at once

Scaling to 10,000+ Users

Component Solution
Local Storage Limit (5-10MB) Use IndexedDB for larger datasets (up to 50MB+)
Sync Bottleneck Implement queue and batch syncing
Database Writes Use write-through cache and message queues
Video Streaming Use adaptive bitrate (HLS/DASH)

Troubleshooting

Common Issues

Issue: Progress not syncing offline

// Check localStorage progressTracker.getPendingSyncs() // Check browser storage quota navigator.storage.estimate().then(estimate => { console.log('Storage used:', estimate.usage, 'bytes'); console.log('Storage available:', estimate.quota, 'bytes'); });

Issue: Videos not loading

Verify YouTube embed URLs are correct and video is public. Check browser console for CORS errors.

Issue: Quiz answers not saved

Ensure JavaScript is enabled and localStorage is available. Check:

// Test localStorage try { localStorage.setItem('test', 'value'); localStorage.removeItem('test'); console.log('localStorage available'); } catch(e) { console.error('localStorage not available:', e); }

Debugging Commands

// In browser console: // View all stored progress progressTracker.exportUserData('user123') // Check storage usage progressTracker.getStorageStats() // Clear corrupted data progressTracker.clearAllData(true) // Force sync progressTracker.syncProgress() // Get specific module progress progressTracker.getModuleProgress('module-1')
