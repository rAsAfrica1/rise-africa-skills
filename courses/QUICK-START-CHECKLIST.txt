DEPENDENCIES & BLOCKERS
===============================================================================

CRITICAL PATH (If these fail, everything fails):
1. Backend API works (progress sync)
2. Database stores progress correctly
3. Files are properly linked
4. Browser localStorage works
5. Video embeds function

IF ANY CRITICAL PATH ITEM FAILS:
- STOP other work immediately
- Fix the blocker
- Re-test entire system
- Then resume normal workflow

COMMON BLOCKERS & SOLUTIONS:
─────────────────────────

Blocker: "Videos won't embed"
Solution: Check YouTube embed URL format, verify video is public, check CORS

Blocker: "Progress not saving"
Solution: Check localStorage enabled, verify API response, check browser console

Blocker: "Database connection error"
Solution: Verify connection string, check credentials, test with simple query

Blocker: "API returns 401/403"
Solution: Verify auth token is valid, check CORS headers, test without auth

Blocker: "Module won't load"
Solution: Check file path, verify HTML syntax, check browser console for errors

PREVENTING BLOCKERS:
- Test every new feature immediately after coding
- Keep detailed error logs
- Have someone test on different devices
- Test with different internet speeds
- Test in offline mode
