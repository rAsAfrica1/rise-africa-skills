QUICK START (30 MINUTES)
================================================================================

STEP 1: Set up web server (5 minutes)
--------
$ cd your-project-directory
$ python -m http.server 8000
# or: npx http-server .
# Then open: http://localhost:8000/example-module-pig-farming.html

STEP 2: Test the example module (5 minutes)
--------
- Open example-module-pig-farming.html in browser
- Try watching a video
- Complete a step
- Answer quiz questions
- Submit a project draft
- Watch progress bar update in real-time
- Close browser and reopen - progress is saved!

STEP 3: Create your first course module (20 minutes)
--------
1. Copy module-template.html to your-course/module-1.html
2. Edit the moduleData object with your content:
   - Change course name
   - Replace video embed URLs
   - Update learning objectives
   - Modify implementation steps
   - Change quiz questions
   - Update project requirements

3. Link both files in your course listing:
   <a href="your-course/module-1.html?userId=USER_ID&courseId=your-course">
     Module 1
   </a>

STEP 4: Test offline functionality (5 minutes)
--------
1. Open module in browser
2. Toggle offline mode (DevTools > Network > Offline)
3. Continue using module - it works!
4. Go back online - progress auto-syncs

ARCHITECTURE OVERVIEW
================================================================================

CLIENT SIDE (Browser)
────────────────────
User opens module.html
    ↓
Load HTML template with default data
    ↓
JavaScript initializes on page load
    ↓
progress-tracker.js loads data from localStorage
    ↓
User interacts with videos, steps, quizzes, projects
    ↓
Each interaction saves to localStorage via progress-tracker.js
    ↓
Progress bar updates in real-time
    ↓
When online: Background periodic sync (every 5 minutes)
    ↓
When offline: Updates queue locally
    ↓
When back online: Automatic sync of all pending changes

SERVER SIDE (Your Backend)
─────────────────────────
Receives POST /api/progress/sync requests
    ↓
Validates user authentication
    ↓
Stores progress in database
    ↓
Returns confirmation
    ↓
Optional: Generates certificates, notifies instructors, etc.

DATA FLOW
────────
Browser localStorage (primary storage)
    ↓ Auto-sync every 5 minutes when online
Server database (backup storage)
    ↓ Used for user statistics, reporting, certificates

function recordPracticalAssessment(moduleId, assessmentId, score) {
    const progress = getModuleProgress(moduleId);
    progress.practicalScore = score;
    progress.practicalCompleted = true;
    updateProgress(moduleId, progress);
}

In module HTML:
<div class="practical-assessment">

DATABASE SCHEMA (PostgreSQL Example)
================================================================================

-- Users table (you already have this)
CREATE TABLE users (
    id UUID PRIMARY KEY,
    username VARCHAR(255) UNIQUE NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Courses table
CREATE TABLE courses (
    id VARCHAR(255) PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    category VARCHAR(100),
    total_modules INT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Modules table
CREATE TABLE modules (
    id VARCHAR(255) PRIMARY KEY,
    course_id VARCHAR(255) REFERENCES courses(id),
    module_number INT,
    title VARCHAR(255),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Module progress (main tracking table)
CREATE TABLE module_progress (
    id BIGSERIAL PRIMARY KEY,
    user_id UUID REFERENCES users(id),
    module_id VARCHAR(255) REFERENCES modules(id),
    videos_watched JSONB,
    steps_completed INT DEFAULT 0,
    quiz_submitted BOOLEAN DEFAULT FALSE,
    quiz_score INT,
    project_submitted BOOLEAN DEFAULT FALSE,
    completed BOOLEAN DEFAULT FALSE,
    completed_at TIMESTAMP,
    synced_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    -- Create index for fast lookups
    UNIQUE(user_id, module_id)
);

CREATE INDEX idx_user_progress ON module_progress(user_id);
CREATE INDEX idx_module_progress ON module_progress(module_id);
CREATE INDEX idx_completion ON module_progress(completed);

-- Points & badges
CREATE TABLE user_points (
    id BIGSERIAL PRIMARY KEY,
    user_id UUID REFERENCES users(id),
    points INT DEFAULT 0,
    total_points INT DEFAULT 0,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE user_badges (
    id BIGSERIAL PRIMARY KEY,
    user_id UUID REFERENCES users(id),
    badge_id VARCHAR(100),
    badge_name VARCHAR(255),
    awarded_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(user_id, badge_id)
);

================================================================================
TROUBLESHOOTING COMMON ISSUES
================================================================================

Issue: "Videos not loading"
────────────────────────────
Solution:
1. Check YouTube embed URL is correct
2. Verify video is public (not private/unlisted)
3. Check CORS settings on server
4. Try incognito/private browsing
5. Check browser console for errors (F12)

Issue: "Progress not saving"
────────────────────────────
Solution:
1. Check browser localStorage is enabled
2. Check if private browsing mode (storage disabled)
3. Check if using outdated browser
4. Look for console errors (F12)
5. Try clearing cache and cookies
6. Manually call: progressTracker.syncProgress()

Issue: "Module won't sync to server"
────────────────────────────────────
Solution:
1. Check internet connection
2. Verify backend API is running
3. Check API endpoint URL in progress-tracker.js
4. Verify authentication token is valid
5. Check CORS headers from server
6. Look for error in browser console

Issue: "Performance is slow"
──────────────────────────
Solution:
1. Check if using old browser
2. Clear browser cache
3. Disable browser extensions
4. Check internet speed
5. Reduce number of videos on page
6. Use video CDN instead of direct hosting
7. Enable gzip compression on server

Issue: "Quiz answers not appearing"
───────────────────────────────────
Solution:
1. Check browser console for JavaScript errors
2. Make sure quiz HTML has proper structure
3. Verify input names are unique
4. Clear browser cache
5. Try different browser
