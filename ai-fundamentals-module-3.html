Lessons

1. Python Basics: Variables and Data Types

In this lesson, you'll learn how to store and work with data in Python. Start by installing Python from python.org and use IDLE or VS Code. A variable is like a labelled container. For example, `price = 500` stores the number 500 in `price`. Python has several basic data types: integers (whole numbers like 500), floats (decimals like 12.5), strings (text like "Nairobi"), and booleans (True/False). You can check a type with `type(price)`. Use meaningful names: `maize_price` is better than `x`.

To assign values, use `=`. You can also do arithmetic: `total = price * 2` gives 1000. Strings can be joined with `+`: `"Hello " + "Africa"` gives "Hello Africa". For numbers, use `+`, `-`, `*`, `/`. Python follows order of operations. Convert between types: `int("100")` turns string to integer, `str(100)` turns integer to string. This is crucial when reading data from files.

In African markets, you might track daily sales. Create variables: `tomato_kg = 3.5`, `price_per_kg = 120`, `revenue = tomato_kg * price_per_kg`. Then print: `print(f"Revenue: {revenue} KES")`. The f-string inserts variables into text. Practice with real data: your monthly expenses, mobile money transactions, or crop yields.

Common mistakes: using `=` instead of `==` for comparison, forgetting quotes around strings, mixing numbers and strings without conversion. Always test small pieces. Use `print()` to see values. Python is case-sensitive: `Price` and `price` are different.

Exercise: Write a script that stores your name, age, and daily wage. Calculate weekly wage (5 days). Print a sentence like "Amina, age 25, earns 3500 KES per week." This builds the foundation for AI, where data is stored in variables before processing.

2. Control Flow and Functions

Control flow lets your program make decisions. Use `if`, `elif`, and `else`. For example: `if rainfall > 50: print("Plant now") elif rainfall > 20: print("Wait") else: print("Irrigate")`. Indentation (4 spaces) is required. You can also loop with `for` and `while`. `for i in range(5): print(i)` prints 0 to 4. `while count < 10: count += 1` repeats until condition fails. Use `break` to exit early, `continue` to skip an iteration.

Functions are reusable blocks. Define with `def greet(name): return f"Hello {name}"`. Call with `greet("Chidi")`. Functions can take multiple arguments and return multiple values. Use `def calculate_profit(revenue, cost): return revenue - cost`. This avoids repeating code. In AI, functions encapsulate tasks like loading data, training a model, or making predictions.

African context: A farmer might use control flow to decide irrigation based on soil moisture sensor readings. A function could compute the average yield from several plots. Example: `def average_yield(yields): return sum(yields)/len(yields)`. Then `average_yield([2.5, 3.0, 2.8])` returns 2.77.

Practice: Write a function `grade(score)` that returns "A" if score >= 80, "B" if >= 70, etc. Then loop through a list of scores and print each grade. This teaches both control flow and functions.

Remember: keep functions small and focused. Use descriptive names. Test with different inputs. This is how you build AI pipelines: data flows through functions that clean, transform, and analyze it. Without control flow, your program can't react to data; without functions, it becomes messy. Master these to write efficient Python for AI.

3. Data Structures: Lists, Tuples, Dictionaries

Lists store ordered items: `prices = [120, 150, 90]`. Access with index: `prices[0]` is 120. Add with `append(200)`. Remove with `remove(150)`. Lists are mutable. Tuples are like lists but immutable: `coordinates = (3.5, 7.2)`. Use tuples for fixed data. Dictionaries store key-value pairs: `crop = {"name": "maize", "yield": 2.5}`. Access with `crop["name"]`. Add new key: `crop["price"] = 50`.

In AI, lists hold datasets, tuples hold shapes or configurations, dictionaries hold parameters. For example, a list of customer transactions: `transactions = [100, 250, 75]`. Sum them with `sum(transactions)`. A dictionary for a machine learning model: `model = {"type": "linear", "learning_rate": 0.01}`.

African example: You run a small shop. Use a list for daily sales: `sales = [1200, 1500, 900, 1800]`. Calculate total: `total = sum(sales)`. Average: `avg = total / len(sales)`. Use a dictionary for inventory: `inventory = {"rice": 50, "beans": 30, "oil": 20}`. Update stock: `inventory["rice"] -= 5`.

Nested structures: list of dictionaries: `customers = [{"name": "Amina", "spent": 500}, {"name": "Kofi", "spent": 300}]`. Loop through: `for c in customers: print(c["name"], c["spent"])`.

Exercise: Create a list of 5 temperatures. Find max, min, average. Create a dictionary of 3 products with prices. Write a function that takes the dictionary and returns the most expensive product. This builds skills for handling real data in AI.

4. NumPy for Numerical Computing

NumPy is the foundation for numerical AI in Python. Install with `pip install numpy`. Import as `import numpy as np`. The core is the array: `arr = np.array([1, 2, 3])`. Arrays are faster and more memory-efficient than lists for math. Create arrays from lists, or use `np.zeros(5)`, `np.ones((2,3))`, `np.arange(0, 10, 2)`.

Operations are element-wise: `arr * 2` doubles each element. `arr + arr` adds corresponding elements. For matrices, use 2D arrays: `matrix = np.array([[1,2],[3,4]])`. Matrix multiplication: `np.dot(matrix, matrix)`. Statistical functions: `arr.mean()`, `arr.std()`, `arr.max()`.

African context: You have rainfall data for 10 farms: `rainfall = np.array([500, 600, 450, 700, 550, 800, 400, 650, 720, 580])`. Compute average: `rainfall.mean()` gives 595. Find farms with above-average rainfall: `rainfall[rainfall > rainfall.mean()]`. This is boolean indexing.

In AI, NumPy is used for feature vectors, weight matrices, and gradients. For example, a simple neural network layer: `output = np.dot(inputs, weights) + bias`. Without NumPy, this would be slow loops.

Exercise: Create a 3x3 array of random numbers using `np.random.rand(3,3)`. Compute row sums, column means, and overall standard deviation. Then create an array of 100 numbers from a normal distribution with mean 50 and std 10. This prepares you for data manipulation and model building.

5. Pandas for Data Manipulation

Pandas handles tabular data like spreadsheets. Install with `pip install pandas`. Import as `import pandas as pd`. The main objects are Series (1D) and DataFrame (2D). Create a DataFrame from a dictionary: `df = pd.DataFrame({"crop": ["maize", "beans"], "yield": [2.5, 1.8]})`. Read CSV: `df = pd.read_csv("data.csv")`.

Inspect data: `df.head()`, `df.info()`, `df.describe()`. Select columns: `df["crop"]`. Filter rows: `df[df["yield"] > 2]`. Add a column: `df["revenue"] = df["yield"] * 100`. Group by: `df.groupby("crop")["yield"].mean()`. Handle missing data: `df.dropna()` or `df.fillna(0)`.

African example: You have a CSV of market sales: columns `date`, `product`, `quantity`, `price`. Load it, compute total revenue per product: `df["revenue"] = df["quantity"] * df["price"]; df.groupby("product")["revenue"].sum()`. Find top-selling product.

Pandas is essential for AI data preparation: cleaning, merging, reshaping. For instance, merge two DataFrames on a common key: `pd.merge(df1, df2, on="id")`.

Exercise: Create a DataFrame with 10 rows of student data: name, age, score. Filter students with score > 70. Add a column "passed" (True/False). Compute average score by age group. This mirrors real-world data tasks before feeding into machine learning models.

6. Matplotlib and Seaborn for Visualization

Visualization reveals patterns. Matplotlib is the base library; Seaborn builds on it for statistical plots. Install both: `pip install matplotlib seaborn`. Import: `import matplotlib.pyplot as plt` and `import seaborn as sns`.

Basic line plot: `plt.plot([1,2,3], [4,5,6])`, then `plt.show()`. Add labels: `plt.xlabel("Days")`, `plt.ylabel("Sales")`, `plt.title("Weekly Sales")`. Scatter plot: `plt.scatter(x, y)`. Bar chart: `plt.bar(categories, values)`. Histogram: `plt.hist(data, bins=10)`.

Seaborn simplifies complex plots. Load a dataset: `sns.load_dataset("tips")`. Then `sns.scatterplot(x="total_bill", y="tip", data=tips)`. For distributions: `sns.histplot(data=df, x="yield")`. For relationships: `sns.pairplot(df)`. For correlation heatmap: `sns.heatmap(df.corr(), annot=True)`.

African context: Plot monthly rainfall for a region. Use a bar chart to compare crop yields across farms. A heatmap can show correlations between temperature, rainfall, and yield.

In AI, visualization helps understand data before modeling and interpret results. For example, plot actual vs predicted values to see model performance.

Exercise: Create a DataFrame with 12 months of sales data. Plot a line chart. Then create a bar chart of average sales per quarter. Finally, use Seaborn to make a boxplot of sales by month. Save figures with `plt.savefig("plot.png")`. This equips you to communicate insights from AI projects.

Practical Reference: Python for AI in African Agribusiness

This practical reference is designed for agribusiness professionals, analysts, and technical managers across Africa who need a working command of Python for AI applications. It consolidates the core lessons from this module â variables and data types, control flow, data structures, NumPy, Pandas, and visualization â into a single job-ready reference. The focus is not on becoming a software engineer. It is on using Python to turn farm, market, weather, and logistics data into decisions that improve yields, reduce waste, and increase margins.

Across the continent, agribusinesses face a common bottleneck: data exists but is scattered across paper records, WhatsApp messages, Excel sheets, and disconnected mobile apps. Python gives you a single toolkit to clean that data, analyze it, and produce charts and models that support pricing, planting, procurement, and credit decisions. Whether you are managing a maize aggregation business in Nakuru, a cocoa cooperative in Ghana, or a cold-chain logistics operation in Lagos, the same core Python skills apply.

Core Syntax You Will Use Every Day

Python basics are not academic. In an agribusiness setting, variables store quantities such as bags of maize, hectares planted, or litres of milk. Data types determine what operations are valid. A float for rainfall in millimetres, an integer for number of farmers, a string for county or region, and a boolean for whether a loan is repaid â these are the building blocks.

Control flow lets you apply business rules. If the moisture content of a grain batch exceeds 13.5%, flag it for drying. If the market price in Nairobi falls below the cost of transport from Kitale, do not dispatch. Functions package these rules so they can be reused across seasons and regions without rewriting logic. This is how you scale a trading or aggregation business without proportionally scaling headcount.

Data structures are where Python becomes genuinely powerful for agribusiness. A list holds a sequence of daily milk yields. A tuple holds fixed coordinates or a fixed contract term. A dictionary maps farmer IDs to their delivery records, or crop names to their expected market prices. Most real-world AI work in agriculture is, at its core, moving data between these structures and applying rules through loops and conditionals.

NumPy and Pandas: The Analytical Engine

NumPy is the foundation for numerical computing. It replaces slow Python loops with vectorized operations on arrays. For agribusiness, this matters when you are processing thousands of farmer records, computing rainfall anomalies across districts, or running statistical models on yield data. A simple NumPy array can hold a season's worth of daily temperatures, and one line of code can compute the mean, standard deviation, or growing degree days.

Pandas builds on NumPy and gives you DataFrames â essentially programmable spreadsheets. This is where most agribusiness AI work happens. You load a CSV of market prices, clean missing values, group by county and month, merge with weather data, and compute correlations between rainfall and yield. Pandas handles time series, joins, pivots, and rolling averages, all of which are essential for seasonal planning and risk assessment.

A practical example: a coffee cooperative in Uganda wants to forecast cherry prices for the next quarter. Using Pandas, they load three years of auction prices, merge them with rainfall and export volume data, and compute a rolling average. NumPy then powers a simple regression. The output is not a perfect prediction, but it is far better than intuition alone, and it can be updated weekly as new data arrives.

Visualization: Making Data Legible to Decision-Makers

Matplotlib and Seaborn turn numbers into charts that boards, cooperatives, and lenders can act on. A line chart of maize prices over 24 months tells a clearer story than a table. A heatmap of rainfall by district and month reveals planting windows. A box plot of yields by seed variety shows which inputs actually perform.

In the African context, visualization must often work on low-bandwidth connections and be readable on mobile screens. Keep charts simple: strong colors, large labels, and clear titles. Seaborn's default styles are cleaner than raw Matplotlib, but both are free and run offline once installed. For reports shared via WhatsApp or email, export as PNG at modest resolution to keep file sizes small.

â  Safety Warning: Data Protection and Responsible AI in Agribusiness

Farmer data â names, locations, yields, loans, and phone numbers â is sensitive personal and commercial information. Under Kenya's Data Protection Act (2019), Nigeria's Data Protection Act (2023), South Africa's POPIA, and the African Union Malabo Convention, you must obtain consent, secure storage, and limit use to stated purposes. Never upload farmer-identifiable data to public AI tools or unsecured cloud notebooks. Anonymize or aggregate before analysis where possible. AI-generated price or credit recommendations must be reviewed by a human before they affect a farmer's income or access to finance. Poor data or biased models can deny credit to smallholders or misprice crops, causing real harm.

Quick Reference Checklist

  • Define your business question first. Before writing code, state the decision you want to improve â pricing, planting, procurement, or credit.
  • Use the right data type. Numbers as int or float, categories as strings, yes/no as booleans. Wrong types cause silent errors.
  • Write functions for repeated rules. Moisture checks, margin calculations, and grading rules should live in functions, not copy-pasted code.
  • Prefer Pandas for tabular data. If your data fits rows and columns, use DataFrames before reaching for loops.
  • Use NumPy for math on arrays. Avoid Python loops over large numeric datasets; vectorize instead.
  • Always inspect data before analysis. Check shape, missing values, and outliers with .info(), .describe(), and .head().
  • Visualize before you model. A simple chart often reveals data errors or patterns that modeling would miss.
  • Protect farmer data. Anonymize, secure, and get consent. Keep a human in the loop for any decision affecting livelihoods.
