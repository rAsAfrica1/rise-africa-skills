## 📞 SUPPORT & MAINTENANCE

### Course Updates
1. Edit the HTML file directly
2. Re-upload to server
3. No rebuilding or compilation needed

### Adding Videos
1. Find YouTube video ID
2. Replace `VIDEO_ID` in iframe: `https://www.youtube.com/embed/VIDEO_ID`
3. Update and redeploy

### Pricing Changes
- Edit price in course file: `<div class="amt">$X.XX</div>`

### Adding New Courses
1. Use template: `*-course.html` and `*-module-N.html` files
2. Follow naming convention: `course-slug-course.html`
3. Update index.html to link new courses
4. Deploy
