Building a Portfolio of Prompts - Your Personal Library

🧠 Brain Opener

Every professional writer has a folder of templates. Every professional coder has a library of functions. Every professional AI user has a library of prompts. Most people rewrite the same prompt every day. Professionals do not.

  • What is a prompt library?
  • Why does saving prompts save time?
  • How do you know which prompt is the best one?
🎁 Reveal a good answer

A prompt library is a personal collection of tested prompts you reuse. Saving prompts saves time because you only solve each type of problem once. You know a prompt is the best one because you have tested it multiple times and it works every time.

📖 Naledi Builds a Library

Naledi was sixteen, in Johannesburg, and had been using Claude for a year. She was fast, but she was inconsistent. Some days the outputs were brilliant. Other days they were useless. She could not tell what made the difference.

One afternoon she opened her browser history and counted. She had typed over two hundred prompts in a month. Reading them back, she noticed something.

Many prompts were almost the same. Twenty variations of "write a good post about X." Thirty versions of "explain Y to a beginner." Forty requests for help with essay intros. She was solving the same problem over and over.

So she started a document. Every time a prompt worked well, she saved it. Every time a prompt failed, she noted what went wrong and rewrote it. After a month, she had twelve prompts that worked every time.

She gave them names. "The Essay Intro Builder." "The Explain Like I Care." "The Two-Sides Table." "The Client Brief." Twelve prompts, twelve names, twelve tools.

Now when she had a task, she did not start from scratch. She opened her document, picked the closest prompt, and adapted it. Her work became faster and better. Not because she was smarter than before, but because she had built a library.

By the end of the year, twelve prompts had become forty. She shared the document with two friends. One of them paid her five dollars for a copy.

💡 The Big Idea

Solve each problem once

A prompt library is like a carpenter's toolbox. You do not invent a hammer every time you need to nail something. You reach for the tool you have already tested. Twelve good prompts, well-tested, beat two hundred improvised ones.

📚 Three Deep Lessons

1

What belongs in a prompt library

A prompt library is not a list of your favourite questions. It is a list of reusable tools. Each one solves a class of problem, not a single instance. "Write an essay intro" is a class. "Write an intro for my essay about water" is not.

Start with the tasks you do most often. For a student: essay intros, chapter summaries, quiz questions, revision tables. For a business user: client briefs, price quotes, service descriptions. Save the version that works every time, and name it.

2

The three-test rule

A prompt earns a place in your library only after it passes three tests. First, it works three times in a row on the same task. Second, it works on a similar but different task. Third, it works when someone else uses it.

Most prompts fail on test three. This is the hardest one, and it is why shared prompts are the most valuable kind. If a prompt only works for you, it is a trick. If it works for anyone, it is a tool.

3

Name your prompts

A prompt without a name is a prompt you will forget. A prompt with a name is a tool you reach for. Names should be short, descriptive, and memorable: "The Essay Intro Builder" not "prompt number 4."

Group them by purpose. All writing prompts together. All analysis prompts together. All planning prompts together. The library grows faster when it is organised. Within a year you will have a personal toolkit nobody else has.

🛠 Hands-On - Build Your First Ten Prompts

You need

  • A phone or laptop
  • A document you can edit
  • A pen and paper
  1. List the ten tasks you do most often with AI.
  2. Write a prompt for each task. Test each one three times.
  3. Keep only the ones that work every time.
  4. Name each one. Group by purpose.
  5. Write the document. Save it somewhere you can always reach.
  6. Every time a prompt fails, rewrite it. Every time it wins, save it.
Why it works: Tested, named, reused prompts save hundreds of hours a year. A library built in one hour repays itself in one week.

🎮 Game - Prompt Battle

2 to 10 players - 20 min

The teacher gives a task: "Summarise this chapter in five bullet points, each under ten words." Every player writes a prompt to do the task, and runs it. Compare outputs. The winning prompt must (1) produce something usable, (2) work again on a different chapter, (3) work when another player uses it. Only the third test decides the winner.

🤖 AI-Era Skill

AI can help you build your own prompt library - by testing prompts and suggesting improvements.

Try this prompt: "Here are three prompts I use often. Test each one on a simple task. Tell me which works best, which words are weak, and rewrite the weakest so it works every time."

Read the AI suggestion, then test it yourself three times. Keep only what passes.

🏆 Project Challenge

Build Your Library of 20

Over two weeks, build a library of twenty tested prompts.

  1. List every task you do with AI in a normal week.
  2. Write a prompt for each. Run each one three times.
  3. Keep only the prompts that work every time.
  4. Name each one. Write the library in a single document.
  5. Group by purpose: writing, planning, analysis, learning, business.
  6. Test every prompt with one other person. Delete anything that fails.
  7. At the end, count how many survived. Twenty is a strong library.
