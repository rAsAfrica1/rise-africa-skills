1. Linear Algebra: Vectors and Matrices

Imagine you run a small shop in Accra and want to predict sales. You have data: daily temperature, rainfall, day of week. Each day's data can be written as a list of numbers, like [32, 0, 3] for 32C, no rain, Wednesday. That list is a vector. A vector is just an ordered list of numbers. In AI, we use vectors to represent everything: a customer's age, income, and purchase history; a photo's pixel values; a word's meaning. For example, a customer profile might be [25, 5000, 2] meaning age 25, income 5000 Ghana cedis, 2 previous purchases.

When you have many such vectors, you stack them into a matrix. A matrix is a rectangular grid of numbers. If you have 100 customers and 3 features each, you get a 100x3 matrix. You can think of it as a table. In Python, using the NumPy library, you can create a matrix like this: `import numpy as np; data = np.array([[25, 5000, 2], [30, 7000, 1], ...])`. NumPy is free and runs on any laptop.

Why do we care? Because AI models learn patterns by doing math on these matrices. For instance, to find the average customer, you can compute the mean of each column. To find how similar two customers are, you can compute the dot product of their vectors. The dot product multiplies corresponding numbers and sums them: [1,2,3] dot [4,5,6] = 1*4 + 2*5 + 3*6 = 32. A higher dot product means more similarity.

In Africa, you can use this to analyze mobile money transactions. Each transaction is a vector: [amount, hour, sender_age, receiver_age]. Stack thousands into a matrix and you can detect fraud by looking for outliers. Tools like Google Colab (free) let you run Python code in the cloud, no powerful computer needed. Start by loading a CSV of your business data with pandas, convert to NumPy arrays, and compute basic statistics. This is the first step to building any AI model.

2. Matrix Operations and Transformations

Once you have data in a matrix, you need to do operations on it. The most common are addition, multiplication, and transposition. Addition is simple: add corresponding elements. But multiplication is where the power lies. To multiply two matrices, you take the dot product of rows of the first with columns of the second. For example, if you have a 2x3 matrix A and a 3x2 matrix B, the result is 2x2. In Python with NumPy: `C = np.dot(A, B)` or `C = A @ B`. This is used everywhere in AI.

Consider a practical case: You run a maize farm in Kenya and want to predict yield based on rainfall and fertilizer. You have historical data: for each season, rainfall (mm) and fertilizer (kg) as a 1x2 vector. You also have weights that tell you how much each factor contributes to yield. Multiplying the input vector by a weight matrix gives you a predicted yield. This is exactly what a neural network does: it multiplies inputs by weights, adds a bias, and applies a function.

Another key operation is transposition, which flips rows and columns. If you have a matrix of customer features (rows=customers, columns=features), transposing gives features as rows. This is useful for certain calculations. Also, matrix inversion solves systems of equations, like finding the best-fit line in linear regression. But inversion is computationally heavy; for large matrices, we use iterative methods.

In Africa, you can apply these operations to optimize transportation routes. For example, a delivery company in Lagos has a matrix of distances between 10 hubs. By multiplying this distance matrix with a vector of package volumes, you can estimate fuel costs. Tools like NumPy and pandas make this easy. Even on a smartphone, you can run Python via Termux or Pydroid. Start by practicing with small matrices: create a 3x3 matrix of your monthly expenses, multiply by a vector of inflation rates, and see the impact. This hands-on approach builds intuition.

3. Probability Basics for AI

Probability is the language of uncertainty. In AI, we rarely know things for sure. For example, a mobile money fraud detector doesn't know if a transaction is fraudulent; it assigns a probability, like 0.85. Probability is a number between 0 and 1, where 0 means impossible and 1 means certain. You calculate it by counting outcomes. If you flip a fair coin, probability of heads is 0.5. In business, if 20 out of 100 customers default on a loan, the probability of default is 0.2.

There are two key rules: the sum rule and the product rule. The sum rule says the probability of either of two mutually exclusive events is the sum of their probabilities. For example, if probability of rain tomorrow is 0.3 and probability of no rain is 0.7, they sum to 1. The product rule says the probability of two independent events both happening is the product. If probability of a customer buying is 0.4 and probability of them paying on time is 0.9, then both is 0.4*0.9=0.36.

Conditional probability is crucial: P(A|B) is the probability of A given B. For instance, P(fraud | transaction amount > 1000) might be higher. Bayes' theorem lets you update probabilities with new evidence: P(A|B) = P(B|A)*P(A)/P(B). This is used in spam filters and medical diagnosis. In Africa, you can use Bayes to diagnose crop diseases from leaf images: start with prior probability of disease, then update based on symptoms.

In practice, you'll use Python's `scipy.stats` or `numpy.random` to simulate probabilities. For example, simulate 1000 days of sales with a 30% chance of high demand: `np.random.choice([0,1], size=1000, p=[0.7,0.3])`. This helps you understand risk. For a small business, you can calculate the probability of running out of stock given average demand and variability. Start by listing possible outcomes and counting frequencies from your own sales data. This builds a foundation for more advanced AI like Bayesian networks.

4. Statistics: Descriptive and Inferential

Statistics helps you summarize data and make decisions. Descriptive statistics describe your data: mean (average), median (middle value), mode (most frequent), and standard deviation (spread). For example, if your daily sales in a week are [100, 150, 200, 120, 180, 90, 160] Ghana cedis, the mean is 142.86, median is 150, and standard deviation is about 38.5. These tell you typical sales and how much they vary. In Python, use `np.mean(sales)`, `np.median(sales)`, `np.std(sales)`.

Inferential statistics goes further: it uses a sample to make conclusions about a larger population. For instance, you survey 100 customers in Nairobi and find 60% prefer mobile money. You can infer that between 50% and 70% of all customers prefer it, with 95% confidence. This is a confidence interval. Hypothesis testing checks if a difference is real. If you test a new fertilizer on 20 plots and get 10% higher yield, a t-test tells you if that's likely due to chance.

In AI, we use statistics to evaluate models. For example, after training a model to predict loan defaults, you calculate accuracy, precision, and recall on a test set. Precision is the fraction of predicted defaults that are correct. Recall is the fraction of actual defaults you caught. These are descriptive statistics of model performance. Inferential statistics help you decide if your model is significantly better than a simple rule.

For African entrepreneurs, statistics can answer questions like: Is there a significant difference in sales between weekdays and weekends? Use a t-test. Or: What is the correlation between rainfall and crop yield? Use Pearson correlation. Tools like Python's `scipy.stats` and `statsmodels` make this easy. Even Excel can do basic statistics. Start by collecting data on your business, compute mean and standard deviation, and plot a histogram. This will give you insights to make data-driven decisions.

5. Calculus: Derivatives and Gradients

Calculus is about change. In AI, we need to know how changing a model's parameters affects its error. That's where derivatives come in. A derivative measures how much a function changes when its input changes slightly. For example, if profit P depends on price x, the derivative dP/dx tells you how profit changes if you increase price by 1 unit. If dP/dx is positive, increasing price increases profit; if negative, it decreases.

In AI, we have many parameters, so we use gradients. A gradient is a vector of partial derivatives, one for each parameter. If you have a model with weights w1, w2, and a loss function L, the gradient is [L/w1, L/w2]. It points in the direction of steepest increase of L. To minimize loss, we move in the opposite direction: w_new = w_old - learning_rate * gradient. This is gradient descent.

Consider a simple linear model: predicted sales = w * advertising_spend. You have data: spend 100, sales 500; spend 200, sales 800. You want to find w that minimizes error. The loss is mean squared error: L = (1/n) * sum((actual - w*spend)^2). The derivative dL/dw = (1/n) * sum(-2*spend*(actual - w*spend)). You can compute this in Python and update w iteratively. Start with w=0, learning rate=0.001, and after many steps, w converges to about 3.5 (since 500/100=5, 800/200=4, average ~4.5, but with more data it adjusts).

In Africa, you can use this to optimize pricing for a kiosk. If you know how demand changes with price (derivative), you can set price to maximize profit. Tools like Python's `sympy` for symbolic derivatives or `autograd` for automatic differentiation make it easy. Even without coding, you can approximate derivatives by calculating change in output over change in input. Practice with small datasets: compute gradient of loss for a linear model by hand, then code it. This understanding is the backbone of training neural networks.

6. Optimization: Gradient Descent

Gradient descent is the workhorse of AI. It's an algorithm to find the minimum of a function. Imagine you're on a hilly landscape in the Rift Valley, blindfolded, and want to reach the lowest point. You feel the slope under your feet and take a step downhill. Repeat until you reach a flat area. In AI, the landscape is the loss function, and the slope is the gradient. You update parameters in the opposite direction of the gradient.

The key parameters are the learning rate (step size) and the number of iterations. If the learning rate is too small, you take forever; too large, you might overshoot and never converge. A common starting point is 0.01 or 0.001. You also need to decide when to stop: when the gradient is near zero or after a fixed number of steps. In practice, you use stochastic gradient descent (SGD) or mini-batch gradient descent, where you compute the gradient on a subset of data to speed up.

Let's apply this to a real problem: predicting maize yield from rainfall. You have 100 data points. Model: yield = w * rainfall + b. Loss = mean squared error. Initialize w=0, b=0. Compute gradients: L/w = average(-2*rainfall*(yield - (w*rainfall+b))), L/b = average(-2*(yield - (w*rainfall+b))). Update: w = w - lr * L/w, b = b - lr * L/b. Repeat 1000 times with lr=0.0001. You'll see w and b converge. In Python, you can code this in 20 lines using NumPy. Libraries like TensorFlow and PyTorch automate this, but understanding the math helps you debug.

In Africa, you can use gradient descent to optimize supply chain costs. For example, minimize total cost = holding cost + ordering cost + transport cost by adjusting order quantities. Or optimize a mobile money agent's cash balance to minimize shortages. Start with simple linear regression on your business data. Use Google Colab to run the code. Plot the loss over iterations to see it decrease. This hands-on practice will demystify AI training.

<h2>Quick Reference Checklist</h2>

<ol style="line-height:1.8;">
<li><strong>Vector check:</strong> Does each farm have a consistent, complete feature vector? Missing values must be imputed or flagged before matrix operations.</li>
<li><strong>Matrix shape:</strong> Confirm dimensions match before multiplication. In agribusiness, rows = observations (farms, seasons), columns = features (soil, weather, management).</li>
<li><strong>Probability calibration:</strong> A 70% predicted chance of pest outbreak should occur ~70% of the time. Test on historical data before trusting it.</li>
<li><strong>Descriptive stats first:</strong> Always compute mean, median, and variance before modeling. Outliers in yield data often reveal data entry errors or genuine anomalies worth investigating.</li>
<li><strong>Statistical significance:</strong> Use p-values and confidence intervals to distinguish real effects from noise. A fertilizer trial with p &lt; 0.05 is more trustworthy than one without.</li>
<li><strong>Gradient check:</strong> Verify your derivative calculations numerically. A wrong gradient means your model learns nothing useful.</li>
<li><strong>Learning rate tuning:</strong> Start at 0.01, monitor loss curve. If loss increases, reduce rate. If loss decreases too slowly, increase rate.</li>
<li><strong>Business validation:</strong> Always ask: does this model improve a real decision? If not, the mathematics is wasted effort.</li>
</ol>
